# Balanced style references

Ian sends Balanced editions made by his API pipeline so the hand-built ones can match their feel
(2026-11-20). They are references for **tone**: short paragraphs and plain restatement, with
no side remarks. They are not references for **length**: they run 45–65% of the Full, and
Ian's target is about 75% ("i like 75"). Do not copy their generalizations either. The
Chapter 24 one turns a single polycystic-kidney case into a general rule.

| File | Full words | API words | Ours |
|---|---|---|---|
| APK2100-Chapter24-Balanced-API.html | 5090 | 2303 (45%) | 3717 (73%) |
| BSC2011-Module6-Balanced-API.html | 3825 | 2436 (64%) | 2983 (78%) |

What the BSC2011 one does worth copying: it keeps one-line concept sentences that a cut list is
tempted to drop ("depends only on breeding individuals"), and it merges a side example into the
list item it illustrates. What not to copy: it turns the dodo into a rule about island species,
says the condor recovery succeeded *because* triage was not applied (the Full says no one would
have tried it under triage), and still carries its pipeline's AUDIT comments and no doctype.

## Concise

`BSC2010-Macroevolution-Concise-API.html` is the layout to follow for a Concise (Ian, 2026-11-20).
It uses definition tables, fragment bullets with → and "e.g.", `<b>` labels, its exam tip, a
two-column Glossary table and Key Takeaways bullets. It runs to 955 words against a 4,202-word Full
(23%). Ian has said to drop images that aren't needed, so keep only the figures the chapter tells
students to know by sight.
